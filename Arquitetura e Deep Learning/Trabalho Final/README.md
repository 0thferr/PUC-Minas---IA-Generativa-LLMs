# Projeto Final de Deep Learning

## Objetivo

Desenvolver, individualmente, uma solução de **Deep Learning** para um problema de livre escolha, aplicando os conceitos estudados ao longo da disciplina.

O projeto deverá contemplar todas as etapas do desenvolvimento de um modelo de aprendizado profundo, desde a definição do problema até a análise dos resultados obtidos.

---

## Objetivos do Projeto

Durante o desenvolvimento, o aluno deverá:

- Definir um problema de aprendizado de máquina;
- Selecionar um dataset adequado;
- Preparar os dados para treinamento;
- Escolher uma arquitetura de Deep Learning compatível com o problema;
- Treinar e avaliar o modelo;
- Interpretar os resultados obtidos;
- Discutir as limitações da solução e possíveis melhorias.

---

## Tema

O projeto poderá abordar qualquer aplicação compatível com Deep Learning, como por exemplo:

- Classificação de imagens;
- Classificação de textos;
- Análise de sentimentos;
- Previsão de séries temporais;
- Reconhecimento de áudio;
- Detecção de objetos;
- Outras aplicações utilizando Redes Neurais.

A escolha do tema deverá ser justificada tecnicamente.

---

## Dataset

Poderá ser utilizado qualquer **dataset público**, desde que sua origem seja informada no código ou na documentação do projeto.

O trabalho deverá apresentar:

- Breve descrição do dataset;
- Quantidade de exemplos;
- Número de classes (quando aplicável);
- Divisão entre conjuntos de treino, validação e teste;
- Pré-processamentos realizados;
- Eventuais limitações dos dados.

---

## Arquitetura

A arquitetura do modelo é de livre escolha, podendo utilizar uma ou mais das seguintes abordagens:

- MLP (Multilayer Perceptron);
- CNN (Convolutional Neural Network);
- RNN (Recurrent Neural Network);
- LSTM (Long Short-Term Memory);
- GRU (Gated Recurrent Unit);
- Transformers;
- Modelos pré-treinados (*Transfer Learning*);
- Combinações entre diferentes arquiteturas.

A escolha da arquitetura deverá ser justificada com base nas características do problema e do dataset.

---

## Entrega

A submissão deverá ser realizada pelo **Canvas**, contendo:

- Código-fonte (preferencialmente em um notebook `.ipynb`);
- Dataset utilizado ou link público para acesso ao conjunto de dados.

---

## Estrutura Esperada do Projeto

O notebook deverá estar completamente executado e incluir os seguintes itens:

1. Definição do problema;
2. Descrição do dataset;
3. Preparação e pré-processamento dos dados;
4. Implementação do modelo;
5. Definição dos principais hiperparâmetros;
6. Treinamento do modelo;
7. Avaliação utilizando métricas apropriadas;
8. Exemplos de previsões realizadas;
9. Análise crítica dos resultados;
10. Limitações encontradas e sugestões de melhorias futuras.

---

## Critérios de Avaliação

O projeto será avaliado considerando:

- Clareza na definição do problema;
- Qualidade do pré-processamento dos dados;
- Adequação da arquitetura escolhida;
- Organização e documentação do código;
- Desempenho do modelo;
- Análise crítica dos resultados;
- Justificativa técnica das decisões tomadas.

---

## Objetivo Final

Desenvolver uma solução completa de Deep Learning que demonstre a aplicação prática dos conceitos estudados na disciplina, evidenciando a capacidade de selecionar, implementar, treinar e avaliar modelos de redes neurais para resolver problemas reais.
