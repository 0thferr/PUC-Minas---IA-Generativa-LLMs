# Trabalho Final – Ciência de Dados Aplicada

## Tema

**Aplicação de Técnicas Supervisionadas ou Não Supervisionadas em Bases Públicas**

---

## Objetivo

Desenvolver um projeto completo de **Ciência de Dados** utilizando uma base pública de dados e aplicando técnicas de **Aprendizado de Máquina**, supervisionado ou não supervisionado.

O projeto deverá abranger todas as etapas do processo de análise de dados, desde a definição do problema até a interpretação dos resultados, destacando possíveis aplicações práticas da solução desenvolvida.

---

## Escolha da Base de Dados

O aluno deverá selecionar uma **base pública de dados** relacionada a uma área de interesse.

Exemplos de áreas:

- Indústria;
- Educação;
- Economia;
- Meio ambiente;
- Mercado de trabalho;
- Saúde;
- Esportes;
- Transporte;
- Finanças;
- Outras áreas de interesse.

A origem do dataset deverá ser informada por meio de um link para a fonte oficial.

---

## Etapas do Trabalho

### 1. Identificação

Apresentar as informações iniciais do projeto, incluindo:

- Título do projeto;
- Fonte dos dados;
- Link para o dataset utilizado.

---

### 2. Definição do Problema

Descrever claramente o problema que será resolvido.

Nesta etapa, deverão ser definidos:

- Tipo de problema (classificação, regressão, agrupamento, regras de associação, entre outros);
- Variável alvo (quando aplicável);
- Objetivos do projeto;
- Métricas de sucesso;
- Resultados esperados.

---

### 3. Coleta e Preparação dos Dados

Realizar a importação e inspeção inicial do conjunto de dados.

As atividades incluem:

- Coleta dos dados;
- Verificação da qualidade das informações;
- Identificação de valores ausentes;
- Identificação de registros duplicados;
- Avaliação da integridade do dataset.

---

### 4. Análise Exploratória de Dados (EDA)

Explorar o comportamento dos dados utilizando análises estatísticas e visualizações.

As análises deverão incluir:

- Estatísticas descritivas;
- Distribuição das variáveis;
- Visualizações gráficas;
- Identificação de padrões;
- Detecção de outliers;
- Relações entre as variáveis.

---

### 5. Pré-processamento dos Dados

Preparar o conjunto de dados para a etapa de modelagem.

As atividades podem incluir:

- Tratamento de valores ausentes por imputação ou remoção;
- Conversão de variáveis categóricas em numéricas;
- Normalização ou padronização das variáveis (quando necessário);
- Seleção de atributos;
- Divisão dos dados em conjuntos de treino e teste.

---

### 6. Seleção e Treinamento do Modelo

Selecionar uma ou mais técnicas de Machine Learning compatíveis com o problema proposto.

Exemplos de abordagens:

#### Aprendizado Supervisionado

- Regressão Linear;
- Regressão Logística;
- Árvores de Decisão;
- Random Forest;
- Support Vector Machine (SVM);
- K-Nearest Neighbors (KNN);
- Redes Neurais.

#### Aprendizado Não Supervisionado

- K-Means;
- DBSCAN;
- Clusterização Hierárquica;
- Regras de Associação (Apriori ou FP-Growth).

Também poderão ser realizados ajustes de hiperparâmetros para melhorar o desempenho dos modelos.

---

### 7. Avaliação do Modelo

Avaliar a qualidade da solução utilizando métricas apropriadas ao tipo de problema.

As análises podem incluir:

- Acurácia;
- Precisão;
- Recall;
- F1-Score;
- ROC-AUC;
- MAE;
- RMSE;
- R²;
- Silhouette Score;
- Outras métricas compatíveis.

Além das métricas, deverão ser apresentados:

- Análise de desempenho;
- Validação utilizando dados de teste;
- Discussão dos principais erros do modelo.

---

### 8. Reflexão Crítica

Apresentar uma análise crítica sobre o projeto desenvolvido.

A discussão deverá abordar:

- Limitações da solução;
- Principais dificuldades encontradas;
- Possíveis aplicações em cenários reais;
- Sugestões de melhorias;
- Trabalhos futuros ou extensões do projeto.

---

## Entregáveis

O aluno deverá entregar um notebook **`.ipynb`** contendo:

- Nome completo no início do notebook;
- Código organizado e comentado;
- Descrição do problema;
- Informações sobre o dataset;
- Análise exploratória dos dados;
- Pré-processamento;
- Implementação dos modelos;
- Avaliação utilizando métricas adequadas;
- Visualizações e gráficos;
- Discussão dos resultados;
- Conclusão final.

---

## Estrutura Recomendada do Notebook

1. Identificação;
2. Definição do problema;
3. Descrição do dataset;
4. Análise exploratória (EDA);
5. Pré-processamento dos dados;
6. Desenvolvimento do modelo;
7. Avaliação dos resultados;
8. Discussão;
9. Conclusão;
10. Referências.

---

## Objetivo Final

Desenvolver um projeto completo de Ciência de Dados que demonstre a aplicação prática de técnicas de Aprendizado de Máquina em um problema real, evidenciando competências em preparação de dados, modelagem, avaliação e interpretação dos resultados, bem como sua relevância para aplicações no contexto profissional.
