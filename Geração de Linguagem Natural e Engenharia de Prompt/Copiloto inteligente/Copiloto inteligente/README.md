# Trabalho 6 — Copiloto Inteligente Corporativo

Release acadêmico: **v1.0-final**.

O projeto consolida T1–T5 em um copiloto para apoio à interpretação da política-piloto de trabalho híbrido da Aurora Tech. A entrega separa evidência determinística local, evidência de LLM real e avaliação humana pendente.

## Conteúdo
- `release/`: manifesto e configuração final.
- `architecture/`: arquitetura e decisões técnicas.
- `evaluation/final/`: avaliação final, gate e evidência de LLM real.
- `risks/`: matriz de riscos.
- `demo/`: roteiro das seis cenas.
- `originais/`: materiais fornecidos nesta conversa.
- `apresentacao.pptx`: apresentação final.
- `release/Trabalho_06_Relatorio_Final.docx`: relatório consolidado.

## Status
- Execução local dos 20 casos: 20/20.
- Evidência adicional com LLM real: GPT-5.6 Luna.
- Avaliação humana: pendente.
- Custo/latência/tokens de API do modelo-alvo: pendentes.
- LangGraph/MCP: não declarados como implementados sem evidência correspondente.

## Regra de reexecução
Qualquer alteração relevante em modelo, parâmetros, prompt, base, fluxo, multimodalidade ou validação exige nova execução dos 20 casos.
